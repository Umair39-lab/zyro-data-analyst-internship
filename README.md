# Zyro Data Analyst Internship - Week 1

Documentation and deliverables for Week 1 of the data analyst internship program.

## 📁 Repository Structure
* **`week-01/`**: Main directory containing all Week 1 assessment items.
  * `environment_test.ipynb`: Python environment connection test.
  * `sql_test.sql`: SQLite query definitions and baseline setups.
  * **`evidence/`**: Verification outputs and task execution logs.

## 🛠️ Environment Setup & Installations
The Python environment uses core data analytics libraries. To replicate the local workspace environment, run the following setup loop:
```bash
pip install -r requirements.txt
```

## 📊 Deliverables Summary
1. **Python Environment Verification (`environment_test.ipynb`)**: Configured and initialized development environment containing baseline data frameworks (`pandas`, `numpy`, `scikit-learn`).
2. **Database Schema Creation (`sql_test.sql`)**: Built verification schemas and loaded data validations utilizing localized SQLite databases.
3. **Evidence Log Tracking (`week-01/evidence/`)**: Saved process executions directly into the tracking tree to remain accessible natively on GitHub.
